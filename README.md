# Southern Style production health

This repository runs hourly GET-only checks for the public Southern Style website and backend availability/access boundaries. It contains no application source tree, live business records, database dumps, private files, credentials or signing keys. Reports contain only check names and HTTP status, never response bodies.

See Actions → Southern Style production health for results. GitHub schedules may be delayed; this is not a guaranteed real-time uptime SLA. The separate Codex heartbeat reports failures/recovery in the owner conversation. Email/SMTP setup remains on hold.
